## 6. 数据正确性门禁

### RAW

任一RAW必须能回查：

```text
DataSource
SourceBinding
CollectTask
CollectRun
RequestSlice
SliceAttempt
请求参数哈希
返回行数
请求时间
```

### CLEAN

任一CLEAN必须具备：

```text
业务主键
业务时间
available_at
规则版本
Schema版本
CleanBatch
质量状态
来源关系
```

### 财务

不能覆盖修订历史。

回测时只能读取：

```text
available_at <= as_of_time
```

### 复权

必须分离：

```text
未复权行情
复权因子
动态复权计算
```

### 质量

`FAILED`不能发布到正式DataSnapshot。

`WARNING`是否发布由质量策略决定。

### 分钟

在迁盘、压缩、归档和恢复完成前：

```text
禁止扩大全市场分钟历史
```

## 7. 数据库要求

所有结构变化进入Alembic。

禁止：

- 人工临时SQL成为唯一实现；
- 修改已经在环境执行过的历史迁移；
- 用JSON大表代替所有领域表；
- 同时维护两套任务事实；
- 用Redis或日志替代正式状态。

建议新增迁移必须保持：

```text
当前0012
→ 新迁移
```

迁移编号由OpenCode依据仓库实际情况决定。
