# 2. 官方来源事实基线

当前 Tushare 官方说明确认：

```text
daily
= A股未复权日线行情

adj_factor
= A股复权因子

前复权：
当日价格 × 当日复权因子 / 锚点复权因子

后复权：
当日价格 × 当日复权因子
```

Tushare 的前复权锚点随查询 `end_date` 变化。

因此，同一历史交易日：

```text
查询结束日不同
→ 前复权价格可以不同
```

这不是数据错误，而是前复权定义本身依赖锚点。

# 3. 平台最重要的价格边界

quantStock1 正式把价格分成两类：

```text
真实市场价格
+
分析连续价格
```

---

## 3.1 真实市场价格

来源：

```text
clean.stock_daily
clean.stock_minute
clean.stock_limit_price
```

特点：

```text
未复权
代表当时真实市场报价/成交价格尺度
```

用于：

```text
模拟成交
涨跌停判断
订单价格
滑点
手续费
持仓市值
真实价格展示
```

---

## 3.2 分析连续价格

由：

```text
未复权价格
+
复权因子
```

确定性生成。

用于：

```text
技术指标
趋势
历史图表
跨除权日连续收益
特征工程
研究比较
```

不能把分析连续价格当成真实成交价。

# 4. CLEAN 日线只保存未复权事实

`clean.stock_daily` 永久保持：

```text
官方未复权 OHLC
```

不增加：

```text
qfq_open
qfq_high
qfq_low
qfq_close
hfq_open
hfq_high
hfq_low
hfq_close
```

原因：

1. 前复权依赖锚点，不存在唯一永久值；
2. 因子可能历史修订；
3. 保存多套价格会产生口径混杂；
4. 相同数据可以确定性重新计算；
5. 回测成交本来就必须使用未复权价格。

因此：

```text
未复权价格 = 基础事实资产
复权价格   = 派生视图/计算结果
```

---

# 5. `pre_close` 的特殊语义

Tushare 日线中的：

```text
pre_close
```

不是简单的“上一交易日实际 close”。

官方定义是：

```text
昨收价（除权价）
```

官方 `pct_chg` 也是基于该除权昨收计算。

因此禁止：

```text
把 pre_close 等同于上一行 close
```

也禁止在除权日用：

```text
close_t / close_(t-1) - 1
```

直接当成真实连续收益。

# 6. 复权因子 CLEAN

当前：

```text
clean.stock_adj_factor
```

仍保存每个：

```text
security_code + trade_date
```

的当前正式复权因子。

字段：

```text
security_code
trade_date
adj_factor
+ 通用治理字段
```

约束：

```text
adj_factor > 0
adj_factor 为有限数值
```

---

# 7. 新增复权因子修订历史

为了能够回答：

```text
“在某个历史时点，系统当时看到的复权因子是什么？”
```

P4 增加一个窄历史表：

```text
clean.stock_adj_factor_history
```

它不是第二套完整日线，也不是每次采集都复制一份因子。

只有当同一：

```text
security_code + trade_date
```

的正式 `adj_factor` 实际发生变化时才新增版本。

建议结构：

```text
adj_factor_version_id UUID PRIMARY KEY
security_code varchar(16) NOT NULL
trade_date date NOT NULL
adj_factor double precision NOT NULL

observed_from timestamptz NOT NULL
observed_to timestamptz NULL

content_hash char(64) NOT NULL
_clean_batch_id UUID NOT NULL
_source varchar(32) NOT NULL
_created_at timestamptz NOT NULL
```

索引：

```text
(security_code, trade_date, observed_from)
```

---

# 8. 因子历史表的业务含义

`stock_adj_factor_history` 表达：

```text
系统观察历史
```

不是：

```text
公司行为真实公告历史
```

即：

```text
observed_from
= quantStock1 从什么时候开始看到这个因子版本
```

不能把它解释为：

```text
公司行为真实发生时间
```

公司行为的真实事件时间，后续需要独立公司行为 DataItem。

# 9. 因子修订规则

同一证券、交易日的新因子到达后：

## 9.1 因子相同

```text
NO_CHANGE
```

处理：

```text
不新增 history 版本
不修改业务值
更新血缘关系即可
```

---

## 9.2 因子变化

处理：

```text
关闭上一 history.observed_to
↓
新增 history 版本
↓
更新 clean.stock_adj_factor 当前正式值
↓
触发受影响复权派生资产失效
```

不能：

```text
直接覆盖当前值
且不留任何历史
```

---

# 10. 前复权公式

定义：

```text
P_raw(t)
= t 日未复权价格

F(t)
= t 日复权因子

A
= 明确的复权锚点交易日

F(A)
= 锚点复权因子
```

前复权：

```text
P_qfq(t | A)
=
P_raw(t) × F(t) / F(A)
```

同一缩放系数应用到：

```text
open
high
low
close
```

---

# 11. 前复权锚点必须显式

quantStock1 禁止 API 或内部函数只接受：

```text
adjust=qfq
```

却不说明锚点。

正式调用至少需要明确：

```text
adjustment_mode = QFQ
anchor_date = YYYY-MM-DD
```

或者由调用场景明确生成锚点，并在结果元数据返回：

```text
price_mode
anchor_date
factor_as_of
normalization_version
```

---

# 12. 前复权的两个合法场景

## 12.1 图表/人工研究

默认允许：

```text
anchor_date = 查询区间最后一个有效交易日
```

例如查询：

```text
2025-01-01 ～ 2025-12-31
```

则：

```text
anchor_date = 区间内最后一个存在因子的交易日
```

结果必须标明锚点。

---

## 12.2 历史回测

不能使用：

```text
今天
最新交易日
回测结束之后
```

的复权因子作为历史锚点。

正式要求：

```text
anchor_date <= 当前回测 as_of_date
```

且因子版本必须满足：

```text
observed_from <= as_of_time
```

这样才能保证当时的回测没有使用未来才观察到的因子修订。

---

# 13. 禁止“永远按今天前复权”

以下做法正式禁止：

```text
2020年的回测
↓
读取2026年的最新因子
↓
把整个2020历史前复权到2026
↓
用于2020策略判断
```

原因：

```text
未来公司行为
未来因子修订
```

会被带回过去。

这属于：

```text
Look-ahead Bias / 未来函数
```

---

# 14. 后复权公式

后复权：

```text
P_hfq(t)
=
P_raw(t) × F(t)
```

同样可应用于：

```text
open
high
low
close
```

后复权不需要查询期末锚点，但价格尺度由来源因子的归一化方式决定。

因此后复权价格：

```text
适合连续分析
不代表真实历史成交价
```

---

# 15. 后复权不能作为成交价格

正式禁止：

```text
用 hfq_close 作为订单成交价
```

因为：

```text
后复权价格是数学变换值
不是当时交易所实际报价
```

同理：

```text
qfq价格
```

也不能直接用于真实成交模拟。

# 17. 收益率的正式口径

## 17.1 官方单日涨跌幅

`clean.stock_daily.pct_change` 保留来源官方口径。

它基于：

```text
除权后的 pre_close
```

适合表达该交易日官方涨跌幅。

---

## 17.2 连续调整收益

研究层需要跨公司行为连续收益时，定义：

```text
R_adj(t)
=
[P_raw(t) × F(t)]
/
[P_raw(t-1) × F(t-1)]
- 1
```

也就是相邻后复权价格的收益率。

它等价于复权尺度下的相对变化，不依赖任意前复权锚点。

---

## 17.3 不能混用

禁止：

```text
今天用官方pct_change
明天用close/昨close
后天用qfq_close
```

同一个 Feature / Strategy 必须声明统一收益口径。

---

# 18. 公司行为与真实组合收益的边界

复权因子能用于：

```text
构造连续价格
构造研究收益
```

但真实持仓组合还涉及：

```text
现金分红
送股
转增
配股
持仓数量变化
现金账户变化
税费
```

当前 P3/P4 首批 DataItem 尚未建立完整公司行为事件链。

因此 P4 正式确认：

```text
复权收益
≠
完整真实账户公司行为结算
```

未来要做高真实性组合回测，必须接入正式公司行为 DataItem，再由 Backtest Engine 处理现金和股数变化。

---

# 19. 当前 P4 回测能力边界

在完整公司行为数据接入前：

可以可靠支持：

```text
连续价格研究
技术指标
信号研究
复权收益分析
基础策略回测
```

不能宣称已经完整支持：

```text
真实现金分红入账
送转股持仓数量变化
配股认购
税费后的精确总收益
```

该边界必须在后续回测验收中明确。

# 20. 分钟价格的基础事实

`clean.stock_minute` 继续只保存：

```text
未复权真实分钟 OHLC
成交量（股）
成交额（元）
```

P4 不增加：

```text
clean.stock_minute_qfq
clean.stock_minute_hfq
```

---

# 21. 分钟复权规则

如果研究需要分钟复权：

```text
分钟bar所属 trade_date
↓
关联该日 adj_factor
↓
按同一日缩放系数调整分钟OHLC
```

例如前复权：

```text
minute_qfq_price
=
minute_raw_price
× F(trade_date)
÷ F(anchor_date)
```

---

# 22. 分钟成交量和成交额不复权

P4 第一版：

```text
只调整价格
```

保持：

```text
volume_share
amount_cny
```

为来源原始市场事实。

禁止自行发明：

```text
adjusted_volume
adjusted_amount
```

需要公司行为可比成交量时，后续单独设计派生指标。

---

# 23. 分钟复权因子缺失

某分钟交易日没有正式复权因子：

```text
不能猜
不能沿用上一日
不能自动填1
```

结果：

```text
该日不能生成正式复权分钟序列
```

质量层记录：

```text
MISSING_ADJ_FACTOR
```

---

# 24. 复权价格是否持久化

P4 正式决定：

```text
基础层不持久化 qfq/hfq OHLC
```

优先：

```text
查询时动态计算
或
Feature/Research阶段按任务生成可缓存派生资产
```

原因：

1. 公式简单；
2. 前复权锚点可变；
3. 因子可能修订；
4. 避免保存多套重复行情；
5. 避免分钟数据指数级放大。

---

# 25. 可缓存派生资产

后续如果性能证据证明动态计算过慢，可以缓存：

```text
AdjustedPriceAsset
```

但必须带完整身份：

```text
data_item
security_scope
date_range
frequency
adjustment_mode
anchor_date
factor_as_of
factor_version_set
normalization_version
generated_at
```

没有这些元数据的缓存：

```text
不能作为正式研究资产
```

---

# 26. 缓存失效规则

任何受影响因子发生修订：

```text
stock_adj_factor_history 新版本
↓
定位受影响 security_code + date range
↓
相关 AdjustedPriceAsset 标记 STALE
```

不能继续把旧缓存当成最新正式结果。

---

# 27. `factor_as_of` 的正式含义

复权计算必须能够声明：

```text
factor_as_of
```

含义：

```text
只允许使用 quantStock1 在该时间点之前已经观察到的因子版本
```

查询规则：

```text
observed_from <= factor_as_of
AND
(observed_to IS NULL OR observed_to > factor_as_of)
```

---

# 28. 实时研究与历史回测的区别

## 实时/今天研究

允许：

```text
factor_as_of = 当前系统时间
```

使用当前正式因子。

---

## 历史回测

必须：

```text
factor_as_of <= 回测当时可见时间
```

不能自动使用数据库今天的 current factor。

---

# 29. 因子当日更新时间与日内策略

当前 Tushare 官方说明复权因子在盘前约 9:15～9:20 完成当日入库。

但 quantStock1 不能仅凭官方目标更新时间假定某个历史日系统一定已经拿到数据。

正式 point-in-time 判断使用：

```text
quantStock1 实际 RawBatch / CleanBatch 时间
```

而不是：

```text
官方理论更新时间
```

因此：

```text
实际系统证据优先
```

---

# 30. 因子缺口

对于存在行情的股票/日期：

```text
需要复权分析
但不存在有效 adj_factor
```

质量问题：

```text
MISSING_ADJ_FACTOR
```

处理：

```text
RAW行情仍可发布为未复权CLEAN
复权派生资产被阻断
```

不能因为缺复权因子把真实未复权行情一起删除。

---

# 31. 异常复权因子

以下情况：

```text
adj_factor <= 0
NaN
Infinity
```

直接：

```text
REJECT
```

---

# 32. 因子突变不是自动错误

复权因子本来就可能因为公司行为发生变化。

因此：

```text
factor发生跳变
```

不能仅凭“变化大”判定错误。

质量层需要结合：

```text
历史序列
公司行为数据（未来）
来源一致性
```

判断。

P4 第一版只做：

```text
有限
>0
存在性
修订追踪
```

不设计拍脑袋的“最大允许变化率”。

---

# 33. 股票日线与涨跌停价格

`clean.stock_limit_price` 保存：

```text
当日真实涨停价
当日真实跌停价
```

属于：

```text
未复权交易规则事实
```

回测涨跌停判断必须使用：

```text
RAW execution_price
+
RAW limit price
```

禁止把涨跌停价格复权后再判断订单能否成交。

---

# 34. 复权对 `pre_close` 的处理

研究层如需要构造复权 `pre_close`：

```text
pre_close_adj(t)
=
pre_close_raw(t) × F(t) / F(anchor)
```

因为来源的 `pre_close(t)` 已是 t 日除权参考昨收。

但正式连续收益优先使用：

```text
官方 pct_change
或
相邻 adjusted close
```

不能把：

```text
前一日 qfq_close
```

和：

```text
当日 raw pre_close
```

混合计算。

---

# 35. 复权对 `change` 和 `pct_change` 的处理

P4 不把：

```text
change
pct_change
```

直接乘复权系数写成新的永久字段。

正式策略：

```text
价格序列需要复权
→ 复权 OHLC

收益需要复权
→ 使用明确收益公式

官方涨跌幅展示
→ 使用 clean.stock_daily.pct_change
```

避免产生多套看似相同、实际语义不同的涨跌幅字段。

---

# 36. 停牌日与复权

停牌日没有官方日线时：

```text
不制造复权K线
```

即使该日存在复权因子，也不能：

```text
复制上一日价格
```

来填出一根假 bar。

---

# 37. 新上市股票

新上市初期：

```text
有行情
有因子
```

则按正常规则计算。

如果因子缺失：

```text
未复权行情仍可用
复权派生阻断
```

不默认：

```text
factor = 1
```

除非来源正式返回 1。

---

# 38. 退市股票

退市后：

```text
历史未复权行情
历史复权因子
因子修订历史
```

全部保留。

不能因为证券当前状态为：

```text
D
```

删除历史复权能力。

# 39. qfq / hfq 的 API 语义

后续 DataContext/API 至少支持：

```text
price_mode = RAW
price_mode = QFQ
price_mode = HFQ
```

QFQ 必须：

```text
anchor_date
```

HFQ 必须：

```text
factor_as_of
```

历史回测两者都必须显式：

```text
factor_as_of
```

# 41. P4.4 第一版公式版本

正式定义：

```text
adjustment_formula_version = adj-v1
```

内容：

```text
QFQ:
P_raw(t) * F(t) / F(anchor)

HFQ:
P_raw(t) * F(t)

ADJUSTED_RETURN:
[P_raw(t) * F(t)]
/
[P_raw(t-1) * F(t-1)]
- 1
```

以后公式变化：

```text
升级版本
不能静默改 adj-v1
```

# 42. P4 实施测试要求

至少自动验证：

1. RAW 日线值没有被修改；
2. qfq 锚点日价格等于该日 RAW 价格；
3. 同一序列换锚点后缩放一致；
4. hfq 符合 `P×F`；
5. qfq 符合 `P×F/F_anchor`；
6. adjusted return 与相邻 hfq 比值一致；
7. 因子相同的连续日期只按同一比例缩放；
8. 因子缺失时复权派生被阻断；
9. 因子 <= 0 被 REJECT；
10. 因子修订生成 history 版本；
11. 相同因子重复采集不生成新 history 版本；
12. `factor_as_of` 能还原旧因子版本；
13. 历史回测不能读取 `factor_as_of` 之后的版本；
14. 分钟 OHLC 能按日因子复权；
15. 分钟 volume/amount 不改变；
16. 涨跌停判断不使用复权价格；
17. 执行价格不使用 qfq/hfq；
18. 停牌日不自动生成复权 bar；
19. 退市股票历史复权数据仍可访问；
20. 复权缓存因因子修订被标记 STALE。

# 43. P4.4 正式决策

本文件确认：

1. `clean.stock_daily` 和 `clean.stock_minute` 永久保存未复权市场事实；
2. qfq/hfq 不作为基础 CLEAN 永久列；
3. `clean.stock_adj_factor` 保存当前正式因子；
4. 新增 `clean.stock_adj_factor_history`，只保存实际发生变化的因子版本；
5. 前复权公式为 `P×F/F_anchor`；
6. 后复权公式为 `P×F`；
7. QFQ 必须显式锚点；
8. 图表研究可默认以查询区间最后有效交易日为锚点；
9. 历史回测禁止以未来交易日或今天作为历史 qfq 锚点；
10. 历史回测必须使用 point-in-time 的 `factor_as_of`；
11. 技术分析/Feature 可以使用复权价格；
12. 订单成交、滑点、涨跌停、真实持仓市值只能使用未复权价格；
13. 官方 `pct_change` 保留官方除权昨收口径；
14. 连续调整收益使用相邻 `P×F` 比值；
15. 复权因子只能构造连续研究价格，不能替代完整公司行为账户结算；
16. 完整现金分红、送转股、配股回测需要未来公司行为 DataItem；
17. 分钟基础表不保存复权副本；
18. 分钟复权只调整 OHLC，不调整 volume/amount；
19. 因子缺失只阻断复权派生，不删除未复权行情；
20. 因子突变本身不自动判错；
21. qfq/hfq 优先动态计算，性能证据不足时不物化；
22. 任何复权缓存必须带锚点、factor_as_of 和公式版本；
23. 因子历史修订必须使受影响的复权缓存失效；
24. 第一版公式版本正式命名 `adj-v1`。
