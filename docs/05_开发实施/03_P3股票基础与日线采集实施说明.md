# P3股票基础与日线采集实施说明

> 日期：2026-07-27  
> 版本：0.3.0  
> 状态：代码实现完成，待真实环境验证

## 本批实现

```text
stock_basic
stock_daily
Scheduler自动增量
```

### stock_basic

按股票生命周期状态分别采集：

```text
L 上市
D 退市
P 暂停上市
G 过会未交易
```

避免只保存当前上市股票造成历史研究偏差。

### stock_daily

按交易日采集全市场日线。

保存Tushare原始单位，不在RAW层做单位转换。

### Scheduler

Scheduler根据交易日历决定是否生成当日`stock_daily`增量任务。

规则：

- 非交易日不创建；
- 当日数据源可用窗口之前不创建；
- 相同交易日重复扫描不产生重复Task；
- 已经建立Watermark后，服务器停机造成的遗漏交易日可自动补齐；
- Scheduler只创建Task，不直接访问Tushare。

## 数据安全

新增RAW内容Hash唯一约束：

```text
raw.tushare_stock_basic
raw.tushare_daily
```

相同原始内容重复采集不会重复存储。

## 限频

`stock_basic`使用独立接口限频配置。

`stock_daily`保留接口理论上限，同时设置较低的实际调用额度，为重试和其他任务保留余量。
