# P3分钟与财务样本采集实施说明

本批仅验证：单股票单交易日1分钟行情、单股票有限范围利润表、单股票有限范围财务指标。

统一执行链仍为：`CollectTask → RequestSlice → Worker → TushareAdapter → RawBatch → RAW → Watermark`。

- 分钟任务身份：`ts_code + frequency + time window`；Tushare返回中没有平台需要的`frequency`，由请求上下文注入RAW。
- 财务任务身份：`ts_code + report date range`；RAW保留公告日期、报告期、更新标志等版本字段，不以“股票+报告期”覆盖历史版本。
- `financial_indicator`保留100条上限保护；本批只跑有限范围样本，不做全历史。
- 新增CapabilityProbe：`stock_minute`、`financial_income`、`financial_indicator`。
- 新增迁移：`0007_sample_runtime`，补齐三个SourceBinding运行配置和RAW内容Hash唯一约束。

真实验收要求：三个Task均`SUCCEEDED`且三个RAW表均有数据；分钟记录`frequency=1min`。
