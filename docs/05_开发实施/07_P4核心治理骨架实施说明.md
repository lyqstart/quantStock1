# P4核心治理骨架实施说明

> 阶段：P4 数据治理与分层存储  
> 批次：P4-1  
> 应用版本：0.7.0  
> 状态：待真实环境验收

## 1. 本批目标

本批只实现 P4 第一条最小完整闭环：

```text
P3 RAW
↓
Clean Task / CleanRun
↓
CleanBatch + Candidate
↓
Quality Task / QualityRun
↓
PASS/WARN → 正式 CLEAN
BLOCK → 不发布
↓
Lineage
```

第一批 DataItem：

```text
trade_calendar
stock_basic
stock_daily
```

不包含分钟、财务、复权派生、多来源合并和归档。

## 3. 任务体系

继续复用 P3 的：

```text
ops.collect_task
ops.request_slice
Worker Lease
Heartbeat
LOST恢复
任务幂等
```

不新增第二套任务队列。

统一 Worker 根据 `stage` 执行：

```text
COLLECT
CLEAN
QUALITY
```

P4 第一批任务定义：

```text
clean:trade_calendar
quality:trade_calendar
clean:stock_basic
quality:stock_basic
clean:stock_daily
quality:stock_daily
```

## 4. 自动串联

P4-1 DataItem 的采集任务成功后自动创建 CLEAN 任务。

CLEAN 成功后自动创建 QUALITY 任务。

质量结果：

```text
PASSED / WARNED
→ 发布正式 CLEAN

BLOCKED
→ CleanBatch=BLOCKED
→ 正式 CLEAN 不变
```

质量阻断属于数据问题，不把任务执行伪装成程序失败。

## 5. CLEAN 标准化

### trade_calendar

```text
exchange → exchange_code
cal_date → calendar_date(date)
is_open 0/1 → boolean
pretrade_date → previous_trade_date(date)
```

### stock_basic

```text
ts_code → security_code
SSE/SZSE/BSE统一交易所编码
保留 L/D/P/G
日期转 PostgreSQL date
空白字符串 → NULL
```

同时维护：

```text
clean.security_master
clean.security_master_history
```

只有业务内容真实变化时才新增观察历史版本。

### stock_daily

```text
ts_code → security_code
trade_date字符串 → date
vol 手 → volume_share 股（×100）
amount 千元 → amount_cny 元（×1000）
ah_vol 手 → 股（×100）
ah_amount 千元 → 元（×1000）
```

NULL 不转 0；非有限数值和无法无损转为整数股数的数据拒绝标准化。

## 6. 第一版质量门禁

已实现的基础 BLOCK 规则包括：

```text
候选拒绝行存在
候选行数与CleanBatch不一致
缺RawBatch输入
交易日历自然日范围不连续
previous_trade_date逻辑错误
stock_basic上市/退市日期逻辑错误
stock_daily交易日不是已发布开市日
stock_daily证券不在已发布security_master
OHLC为空/非有限
OHLC高低关系错误
成交量/成交额为负
```

P4-1 先验证治理骨架；全市场 ExpectedDailySet 完整度等后续规则按设计继续扩展。

## 7. 发布保护

正式 CLEAN 只在 QUALITY 通过后写入。

```text
Candidate
↓
Quality
├─ PASS/WARN → 事务内发布
└─ BLOCK      → 不修改正式CLEAN
```

同一业务值重复执行时不做无意义 UPDATE。

## 10. 运行可靠性

CleanRun / QualityRun 在正式处理事务前独立登记。

Worker 失联时：

```text
RUNNING Run
→ LOST
→ RequestSlice RETRY_WAIT
→ 新Worker接管
```

代码/数据库异常时：

```text
Run → FAILED
Task → FAILED
```

QUALITY 执行异常不会让候选数据误发布。

Worker 注册/心跳会同步：

```text
worker_type=unified
version=当前APP_VERSION
```

避免监控显示旧版本。
