# P4日线成交量精确换算修复说明

## 问题

P4-1真实验收中，`stock_daily` 的5526条RAW记录有480条被清洗拒绝。

数据库精确十进制检查证明这些记录的 `vol × 100` / `ah_vol × 100` 都是整数股；但应用旧实现先转 Python 二进制浮点数，再使用 `is_integer()` 判断。部分合法两位小数在二进制浮点表示中会产生极小误差，因此被误判。

真实统计：

```text
vol_float_fraction=465
ah_vol_float_fraction=19
实际被拒绝记录=480（其中4条同时命中）
```

## 修复

日线“手→股”的精确整数换算改用：

```text
Decimal(str(value)) × 100
```

只有十进制精确结果不是整数股时才拒绝。

未放宽数据质量规则。
