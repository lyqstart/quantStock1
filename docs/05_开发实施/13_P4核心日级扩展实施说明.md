# 3. stock_adj_factor

RAW：

```text
raw.tushare_adj_factor
```

CLEAN：

```text
clean.stock_adj_factor
```

标准化：

```text
ts_code    → security_code
trade_date → date
adj_factor → double precision
```

阻断：

```text
证券代码非法
日期非法
adj_factor为空
adj_factor非有限数
adj_factor <= 0
证券不在正式security_master
非正式开市日
```

来源因子发生真实变化时：

```text
更新当前 clean.stock_adj_factor
+
新增 clean.stock_adj_factor_history 版本
```

相同因子重复执行：

```text
UNCHANGED
不增加历史版本
```

```text
证券身份
交易日
负股本/负市值
limit_status枚举
与 clean.stock_daily.close 交叉一致性
```

```text

```

```text
合法“无停复牌事件”
允许 Quality PASS 并发布 0 行批次
```

# 6. stock_limit_price

RAW：

```text
raw.tushare_stk_limit
```

CLEAN：

```text
clean.stock_limit_price
```

正式范围：

```text
security_master 中的 A 股标准证券
```

来源中其他证券：

```text
SKIP
reason=OUT_OF_SCOPE_SECURITY
```

SKIP 继续记录到：

```text
clean.clean_skipped_row
```

质量检查：

```text
pre_close > 0
up_limit > down_limit
全部价格有限
交易日合法
日线存在时：high <= up_limit 且 low >= down_limit
```


```text
必须确认该采集任务确实持有物理RAW行
```
