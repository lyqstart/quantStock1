# 第2步数据底座验收计划

> 对应任务：S2-001—S2-025
> 基线：`c6e9751`
> 状态：已确认，等待执行

## 1. 阻断原则

任一P0验收失败：

```text
第2步不通过
```

以下不能豁免：

- 数据来源无法追溯；
- 财务修订被覆盖；
- 防未来失败；
- FAILED数据可被正式查询；
- 重跑产生不可控重复；
- 数据库恢复失败；
- stable迁盘无回滚；
- 全市场分钟在系统盘继续扩张。

## 2. 验收组

### A 迁移与数据库

- 空库从零升级到head；
- 当前库从0012升级；
- 唯一约束、外键和检查约束有效；
- downgrade或前向修复方案明确；
- 迁移前后表和数据量核对。

### B 任务可靠性

- Task、Run、Slice、Attempt历史不覆盖；
- Lease超时可恢复；
- Worker失联形成LOST；
- 重试保留失败Attempt；
- 取消和暂停有效；
- 幂等键阻止重复正文；
- 行数命中上限触发拆分。

### C RAW、CLEAN和质量

- 任一RAW可回查请求；
- RAW哈希可验证；
- CLEAN保留规则和来源；
- 财务修订多版本；
- available_at正确；
- 复权分层正确；
- FAILED不能发布；
- WARNING按策略发布；
- Gap补采后验证关闭。

### D Lineage和审计

- RAW→CLEAN→QUALITY直接关系可查；
- lineage_edge上下游可查；
- AuditEvent只追加；
- 状态变化有actor、reason、trace；
- 上游失效能列出影响对象。

### E DataContext和DataSnapshot

- 单股、范围和频率查询；
- 日线、分钟、财务和事件；
- as_of_time；
- available_at_cutoff；
- 质量策略；
- 复权策略；
- Snapshot不可变；
- 同一Snapshot重复查询一致；
- DataContext不访问RAW；
- 防未来测试全部通过。

### F API

- `/api/v1`契约；
- 长任务返回task_id；
- 查询结果包含数据语义；
- 错误不泄露密钥；
- 查询有超时；
- 运维查询不扫描整张分钟表。

### G 容量、迁盘、归档和恢复

- server-test独立；
- SSD目标目录预检；
- 迁盘演练；
- 回滚演练；
- 分钟压缩基准；
- 归档Checksum；
- 归档恢复；
- 数据库全量备份；
- 新数据库恢复；
- 应用连接恢复库并通过健康检查。
