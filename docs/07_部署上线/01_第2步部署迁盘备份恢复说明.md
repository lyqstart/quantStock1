# 第2步 部署/迁盘/备份/恢复操作说明

> 所有 stable 操作标记 **WAITING_USER_EXECUTION**，由用户在确认后手动执行。

## 1. server-test 环境部署

### 1.1 启动测试环境
```bash
# WAITING_USER_EXECUTION
docker compose -f compose.test.yml up -d --wait
```

### 1.2 验证隔离
```bash
# WAITING_USER_EXECUTION
# 确认端口不冲突
docker compose -f compose.test.yml config | grep -A5 ports
```

### 1.3 执行迁移
```bash
# WAITING_USER_EXECUTION
export QUANTSTOCK1_ENV=test
export QUANTSTOCK1_TEST_DATABASE_URL="postgresql+psycopg://quantstock1_test:change_me@localhost:15432/quantstock1_test"
alembic upgrade head
```

## 2. 迁盘操作

### 2.1 预检
```bash
# WAITING_USER_EXECUTION
bash scripts/db_migrate_disk/precheck.sh
```

### 2.2 迁盘（生成命令，不自动执行）
```bash
# WAITING_USER_EXECUTION
bash scripts/db_migrate_disk/migrate.sh --dry-run
```

### 2.3 回滚
```bash
# WAITING_USER_EXECUTION
bash scripts/db_migrate_disk/rollback.sh
```

## 3. 备份操作

### 3.1 全量备份
```bash
# WAITING_USER_EXECUTION
bash scripts/db_backup/full_backup.sh --target /backup/quantstock1
```

### 3.2 验证备份
```bash
bash scripts/db_restore/verify.sh --backup /backup/quantstock1/latest.dump
```

## 4. 恢复操作

### 4.1 恢复到测试库
```bash
# WAITING_USER_EXECUTION
bash scripts/db_restore/restore.sh --backup /backup/quantstock1/latest.dump --dry-run
```

### 4.2 恢复后验证
```bash
bash scripts/db_restore/verify.sh --backup /backup/quantstock1/latest.dump
```

## 5. 分钟压缩归档

### 5.1 应用压缩策略
```bash
# WAITING_USER_EXECUTION
psql -f scripts/minute_archive/compress_policy.sql
```

### 5.2 归档旧数据
```bash
# WAITING_USER_EXECUTION
bash scripts/minute_archive/archive.sh --dry-run
```

## 6. 注意事项

1. 所有 stable 操作必须由用户确认后手动执行
2. 迁盘前必须完成预检（磁盘空间、权限、PG版本）
3. 备份必须包含 .dump + .sha256 + manifest
4. 恢复后必须验证 Alembic 版本、表行数、checksum
5. 分钟压缩策略应用后不可逆（压缩后的分区查询可能变慢）
