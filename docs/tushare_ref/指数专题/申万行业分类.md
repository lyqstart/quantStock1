## 申万行业分类
----

接口：index_classify
描述：获取申万行业分类，可以获取申万2014年版本（28个一级分类，104个二级分类，227个三级分类）和2021年本版（31个一级分类，134个二级分类，346个三级分类）列表信息
权限：用户需2000积分可以调取，具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

**输入参数**

名称 | 类型  | 必选 | 描述
---- | ----- | ---- | ----
src | str | N | 版本（默认为SW2021，可选SW2014）

**输出参数**

名称 | 类型 | 描述
--- | ---- | ----
index_code | str | 行业代码
industry_name | str | 行业名称
level | str | 行业级别（L1一级行业，L2二级行业，L3三级行业）
industry_code | str | 行业编码
is_pub | str | 是否发布指数（1发布 0不发布）
parent_code | str | 上级行业编码

**接口示例**

```python

pro = ts.pro_api()

#获取申万行业分类2021版
df = pro.index_classify(level='L1', src='SW2021')

#获取申万行业分类2014版
df = pro.index_classify(level='L1', src='SW2014')

```
